# Salinity Lab · 盐度实验室

一个基于 Canvas 的交互式水体盐度模拟器。拖动装饰物布置水族箱，调节盐度滑块，实时观察水体状态变化与蟹类的出现／消失。

零依赖纯静态站点，无需构建、无需联网即可运行。

![预览](效果预览.png)

## 功能

- **拖拽布置**：8 种水族箱素材（鹅卵石、水草、贝壳、珊瑚、沉木、彩砂、小鱼、气泵）可从左侧托盘拖入水族箱；拖回托盘即收回
- **盐度调节**：滑块范围 0–35‰，同时以 ‰ 与 g/L 双单位显示；键盘 `←` `→` 每次微调 0.5‰，`Shift` + 方向键每次 2‰
- **实时判定**：根据当前盐度给出状态判定、白话水体名称，并在刻度条上标记临界点
- **生物响应**：盐度进入适宜区间后，蟹类会按配比分批出现；超出耐受范围则淡出。两类个体（成体／幼体）混合出现，峰值时数量最多
- **存活率曲线**：右下角展示盐度—存活率关系，当前位置实时高亮
- **视觉反馈**：水体颜色、密度、气泡速度随盐度变化；含光束、气泡、砂床与玻璃反光

## 运行

直接用浏览器打开 `index.html` 即可。推荐 Chrome / Edge / Firefox 最新版。

如需在本地起一个 HTTP 服务：

```bash
python3 -m http.server 8000
# 或
npx serve .
```

## 构建单文件版

如果需要一个可离线分发、不依赖任何外部文件（图片全部内嵌为 base64）的独立 HTML：

```bash
node build.js
```

产物为 `dist/salinity-lab.html`。

## 技术说明

- **渲染**：Canvas 2D。水波、光束、气泡、砂床、玻璃反光全部程序化绘制
- **素材**：装饰物为内联 SVG，通过 `Image` 对象加载后 `drawImage` 绘制；蟹类素材为位图 PNG
- **动画**：`requestAnimationFrame` 主循环，位移按 `dt / 16.667` 归一化，保证不同刷新率下速度一致
- **尺寸适配**：画布尺寸由 `window.innerHeight` 推算而非测量父容器，避免布局循环依赖；画布按 `devicePixelRatio`（上限 2）放大以保证高清屏清晰度
- **交互**：Pointer Events，配合 `setPointerCapture` 支持鼠标与触摸

### 关于盐度区间

面板中的分带区间（<8‰ 无法孵化 / 8–13‰ 勉强 / 13–30‰ 适宜 / 30–33‰ 偏咸 / >33‰ 无法存活）参考中华绒螯蟹（大闸蟹）溞状幼体的适盐范围整理，用于演示目的。若用于教学或科研场景，请以权威文献与本地养殖实践为准。相关数据集中在 `app.js` 的 `BANDS` 与 `CRAB_TIERS` 两个数组中，便于自行调整。
